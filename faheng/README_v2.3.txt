Benchmark 标注工作台 v2.3 使用说明

一、取消评分后的状态
- 第一次点击某个分数：选中评分。
- 再次点击同一个分数：取消评分。
- 取消后，该任务立即回到“待标注”，不会继续显示“审核中”。
- 如果这条任务之前已有 Reviewer A/B 的通过状态，系统会把 A/B 决策重置为 pending，需要重新复核。
- Reviewer 姓名和备注会保留，方便重新审核。

二、误删任务怎么恢复
方法 1（最快）：
- 在单条任务左侧“当前任务”一栏，点击“恢复误删（N）”。
- 系统会直接打开“任务管理 / 回收站”。
- 点击某条右侧的“恢复这一条”。

方法 2：
- 点击顶部“添加任务”或“导入任务”打开“语料管理”。
- 切换到“任务管理 / 回收站”。
- 在“误删任务回收站”中逐条恢复，或者点击“恢复全部已删除任务”。

三、恢复后的状态
- 恢复的任务会重新出现在任务池和搜索结果里。
- 状态统一从“待标注”开始。
- 删除前已经移除的评分、审核结果不会自动恢复，避免把旧审核误当成当前有效结果。

四、打开方式
- 完整解压本文件夹。
- 保持 index.html 和 data/frontend_pool.js 的相对目录不变。
- 双击 index.html 使用。
